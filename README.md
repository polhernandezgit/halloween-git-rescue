
# The Halloween Commit: Horror at the Server Room

## 1. Presentació i entorn

Aquesta pràctica consisteix a reconstruir un repositori Git, gestionar branques, resoldre conflictes, recuperar un estat segur i publicar el projecte a GitHub.

**Sistema operatiu:** Windows  
**Entorn de desenvolupament:** Visual Studio Code  
**Terminal:** PowerShell  
**Sistema de control de versions:** Git
